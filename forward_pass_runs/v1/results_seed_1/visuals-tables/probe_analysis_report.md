# Raw Activation Probe Analysis

This report uses a five-level evidence ladder. Text baselines are diagnostic, not an automatic rejection gate, because many linguistic variables are intentionally surface-visible.

## Counts

- Candidate activation probes: `3,840`
- Best activation probes: `80`
- Text baseline runs: `240`
- Null control runs: `96,000`
- Variables: `40`

## Evidence ladder

1. **Activation recoverability:** sentence-level basis vs changed classification from activations.
2. **Text/artifact control:** records whether text baselines also solve the task. This narrows the claim but does not automatically reject surface-visible variables.
3. **Directional consistency:** basis → changed deltas must form a stable held-out direction.
4. **Split generalization:** successful performance must occur on held-out marker families or lexical domains.
5. **Learned activation direction viability:** the learned direction must move held-out basis activations toward the changed class under the selected probe.
